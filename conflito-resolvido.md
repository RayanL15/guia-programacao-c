# Conflito controlado

Este guia apresenta uma introdução prática aos fundamentos de Git e GitHub, voltada para estudantes iniciantes e para a organização de projetos.

## Resolução

Durante o desenvolvimento do projeto, foram criadas alterações diferentes na mesma parte deste arquivo em duas branches.

Ao realizar o merge, o Git identificou que não poderia escolher automaticamente qual versão deveria permanecer.

O conflito foi resolvido manualmente combinando as duas versões em um único texto coerente.
