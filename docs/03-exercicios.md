# Exercícios

## Exercício 1 — Entrada de dados

Crie um programa que solicite o nome e a idade do usuário e depois mostre as informações na tela.

## Exercício 2 — Condicional

Crie um programa que receba a idade de uma pessoa e informe se ela é maior ou menor de idade.

## Exercício 3 — Switch

Crie um programa que apresente um menu com diferentes opções e utilize `switch` para executar a opção escolhida.

## Exercício 4 — Repetição

Crie um programa que utilize `for` para mostrar os números de 1 até 10.
