# Introdução à Linguagem C

A linguagem C é uma linguagem de programação criada na década de 1970 e utilizada até hoje em diferentes áreas da computação.

Ela permite trabalhar com conceitos importantes de programação, como variáveis, condições, repetições e funções.

## Estrutura básica

Um programa simples em C pode ser escrito assim:

```c
#include <stdio.h>

int main(void) {
    printf("Ola, mundo!");

    return 0;
}

/* O #include <stdio.h> permite utilizar funções de entrada e saída, como printf e scanf.

A função main representa o ponto inicial de execução do programa. */
