# Guia Básico de Programação em C

## Objetivo

Apresentar os conceitos básicos da linguagem C de forma simples, ajudando iniciantes a compreender a estrutura de um programa, variáveis, entrada e saída de dados, estruturas condicionais e estruturas de repetição.

## Público-alvo

Este guia foi criado para estudantes iniciantes em programação que estão começando a aprender a linguagem C.

## Pré-requisitos

- Conhecimentos básicos sobre computadores;
- Visual Studio Code ou outro editor;
- Compilador C instalado;
- Interesse em lógica de programação.

## Estrutura do guia

- `docs/01-introducao.md`
- `docs/02-conceitos.md`
- `docs/03-exercicios.md`
- `docs/04-referencias.md`
- `exemplos/`

## Como navegar

Recomenda-se seguir os conteúdos na ordem numérica, começando pela introdução, depois pelos conceitos e, por fim, pelos exercícios.

A pasta `exemplos` contém programas em C utilizados para colocar os conteúdos em prática.
